## English summary

This Perspective argues that computational models can link biologically realistic circuit mechanisms to behavioral symptoms in psychiatric disorders. It describes identifying core deficits that cut across diagnostic categories and using models for diagnosis. The full text was not accessed, so the specific circuit experiments are not confirmed here.
